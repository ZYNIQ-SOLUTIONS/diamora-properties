# Diamora Properties — Design Tokens

## 1. Color System (Luxury Light Mode)

### Core Neutrals
- `--color-bg-base`: `#FDFBF7` (Diamond Alabaster — light canvas)
- `--color-bg-surface`: `#F5EEDC` / `#FAF6EC` (Warm Champagne Surface)
- `--color-bg-card`: `#FFFFFF` (Pure Card White)
- `--color-bg-card-hover`: `#FAF8F3` (Hover state)
- `--color-text-primary`: `#050608` (Obsidian Core / High Contrast Onyx)
- `--color-text-secondary`: `#525866` (Platinum Slate / Refined Body Copy)
- `--color-text-muted`: `#8E9BAE` (Muted labels & hints)

### Imperial Gold Accents (From Branding Kit)
- `--color-gold-primary`: `#D4AF37` (Imperial Gold)

## 2. Typography
- `--font-display`: `'Cinzel', serif` (Headings, titles, brand wordmark)
- `--font-body`: `'Montserrat', sans-serif` & `'Plus Jakarta Sans', sans-serif`

## 3. Radii & Spacing
- Scale: `2px`, `4px`, `8px`, `16px`, `24px`, `40px`, `60px`, `90px`
- Card Radius: `4px` / `8px` (Architectural sharp luxury edges)
- Button Radius: `2px` / `4px` or full pill for quick contact triggers
